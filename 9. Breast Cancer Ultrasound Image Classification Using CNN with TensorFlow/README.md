# Breast Cancer Ultrasound Image Classification Using CNN with TensorFlow

## Overview

This project demonstrates the development of a deep learning pipeline for automated breast ultrasound image classification using a Convolutional Neural Network (CNN) implemented in **Python** with **TensorFlow/Keras**. The objective is to classify breast ultrasound images into two categories to support AI-assisted medical image analysis.

The project covers the complete machine learning workflow, including data loading, preprocessing, model development, training, validation, performance evaluation, and visualization of results.

## Dataset

The project uses the **BreastMNIST** dataset from the **MedMNIST** benchmark collection, a publicly available dataset designed for medical image classification research. BreastMNIST consists of breast ultrasound images labeled for binary classification and provides a standardized benchmark for evaluating deep learning models in medical imaging.

**Dataset:** https://medmnist.com/

## Workflow

1. Load the BreastMNIST dataset.
2. Preprocess and normalize image data.
3. Split the dataset into training, validation, and test sets.
4. Design and implement a CNN architecture using TensorFlow/Keras.
5. Train the model and monitor learning performance.
6. Evaluate model performance on the test dataset.
7. Visualize training history and prediction results.
