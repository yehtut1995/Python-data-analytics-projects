# Text Mining and Sentiment Analysis on IMDB Movie Reviews

This project contains a Jupyter notebook that demonstrates an end-to-end text-mining workflow on the IMDB movie review dataset.

Key components:
- download and prepare the IMDB dataset
- load review texts from disk into pandas DataFrames
- compare tokenization approaches, including whitespace and Treebank tokenization
- build Bag-of-Words and TF-IDF embeddings with scikit-learn
- train and evaluate classifiers such as Linear SVM and Random Forest

The notebook includes detailed code cells and explanations, for a presentation of applied NLP and machine learning work.
